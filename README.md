## 🧠 O Que Aprendi Neste Projeto

Durante a criação e publicação deste portfólio, os principais aprendizados técnicos e práticos foram:

* **Arquitetura de Informação e UI/UX:** Estruturação visual focada na conversão e na leitura rápida de recrutadores e clientes, priorizando clareza em seções de apresentação, habilidades e cases.
* **Layouts com Flexbox e CSS Grid:** Construção de grades responsivas para cards de projetos e alinhamento preciso de elementos em diferentes resoluções.
* **Design Responsivo e Mobile-First:** Uso consistente de Media Queries e unidades relativas (`rem`, `vh`, `vw`) para garantir navegação fluida em celulares, tablets e desktops.
* **Interatividade com JavaScript:** Implementação de menus móveis interativos (hambúrguer), rolagem suave entre seções (`smooth scroll`) e manipulação de classes ativas.
* **Otimização de Recursos Web:** Compactação e ajuste de assets de imagens e ícones para melhorar a performance de carregamento e tempo de resposta da página.
* **Fluxo de Deploy e Versionamento:** Configuração e publicação contínua do projeto via GitHub Pages integrado ao fluxo de commits com Git.

## 🚀 Funcionalidades

* [x] **Seção Hero (Apresentação):** Chamada de impacto com resumo profissional e call-to-action (CTA).
* [x] **Galeria de Projetos:** Cards com imagens, descrições, tags de tecnologias e links diretos para código e demonstração.
* [x] **Habilidades & Tecnologias:** Exibição clara do ecossistema de ferramentas dominadas.
* [x] **Menu Responsivo:** Barra de navegação adaptável com suporte a dispositivos móveis.
* [x] **Links de Contato:** Acesso direto a redes profissionais, e-mail e formulário/redirecionamento.
